# 游戏资讯日历看板 - 前端需求

---

## 一、技术栈

- **框架**：Vite + Vue3（单文件组件，组合式 API setup）
- **样式**：Tailwind CSS
- **UI 组件库**：按需引入（如 Element Plus / Ant Design Vue）
- **日期处理**：Day.js
- **部署**：Vite 构建为静态资源，Docker 中 Nginx 托管（支持一键部署）

---

## 二、核心视图：日历主面板

### 基础渲染

- 按自然月网格展示，最小颗粒度为"日"
- 支持指定年月跳转
- 无数据的日期单元格保持空白

### 全局筛选

- **游戏多选**：仅显示选中游戏有数据的日期
- **文本搜索**：对别名 / 原始描述 / 活动信息进行模糊检索

### 单元格 UI

- 展示上限：单日最多显示 N 条（如 3 条），溢出渲染为"+N 更多"按钮
- 标签化展示：每条数据以"游戏名 Tag"形式展示
- 优先级映射：Tag 背景色绑定优先级（高 / 中 / 低 / 无 → 不同色系）
- 完结标识：资源位 = 是 时，Tag 附加完结标识（如对勾 icon）

### 详细列表（侧栏 / 弹窗）

- 点击任意日期触发，列出当天所有数据
- 排序：同天内按优先级降序（高 → 中 → 低 → 无）
- 单条展示字段：
  - 别名 / 原始描述
  - 优先级
  - 资源位（完结状态）
  - **详情链接**（爬虫数据的原始链接，可点击跳转）
  - 游戏负责人列表

---

## 三、交互操作

### 新建自定义日程

- 下拉选择游戏（数据源：映射表 + 爬虫历史库去重）
- 支持"添加新游戏"并填入负责人列表（自动触发映射表写入）
- 录入项：描述、优先级、资源位
- 提交后写入用户事件表

### 修改已有数据

- 通用可改项：优先级、资源位（标记任务完成）、别名
- 爬虫数据和自定义事件均可修改上述属性

### 删除逻辑

- **自定义事件**：物理删除
- **爬虫数据**：通过"隐藏标记"实现前端不可见（支持撤销恢复）
- 与后端定期过期清理不冲突（过期数据自动清理时，关联的标注记录一并删除）

### 状态更新

- 侧栏 / 弹窗内 CRUD 操作后，直接修改 Vue 响应式状态就地更新日历视图
- 禁止重新请求整月接口

## 四、数据表结构（后端需配合）

### 爬虫原始表 `game_news`（已有，只读）

| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| game | 游戏名 |
| info | 资讯描述 |
| link | 详情链接 |
| online_date | 计划上线时间 |
| created_at | 抓取时间 |

### 用户标注表（新增，关联爬虫表）

| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| news_id | 关联 game_news.id（外键） |
| priority | 优先级（3=高 / 2=中 / 1=低 / 0=无） |
| alias | 别名 |
| resource_ready | 资源位（Boolean，是否完结） |
| hidden | 隐藏标记（Boolean，前端不可见） |

### 用户事件表（新增）

| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| game | 游戏名 |
| description | 事件描述 |
| event_date | 事件日期 |
| priority | 优先级（同上） |
| resource_ready | 资源位（Boolean） |
| alias | 别名 |

### 游戏负责人映射表（新增）

| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| game | 标准游戏名（唯一） |
| owners | 负责人列表（JSON Array，如 `["张三", "李四"]`） |

## 五、接口需求

### 统一查询

- 合并爬虫 + 标注 + 用户事件，返回标准化 JSON
- 必须支持：`start_date`、`end_date`、游戏筛选列表、搜索关键词
- 排序：日期升序 + 优先级降序
- 爬虫数据需附带 `link` 字段

### CRUD 接口

- **标注操作**：更新优先级 / 别名 / 资源位 / 隐藏标记（针对爬虫数据）
- **事件操作**：完整增删改（针对自定义事件）
- **负责人管理**：按游戏名查询 / 新增 / 修改负责人列表

### 原则

- 前端查询完全依赖后端聚合后的标准化 JSON
- 所有接口不包含操作用户 UID（单用户系统）
